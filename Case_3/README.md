# Учебный S7 Airlines чатбот

Учебный чат-бот на Python для пассажиров S7 Airlines.

Бот умеет отвечать на простые вопросы по темам:

- приветствие;
- билеты;
- регистрация;
- багаж;
- статус рейса;
- программа лояльности;
- поддержка;
- завершение диалога.

Проект сделан в учебных целях. Бот не является официальным ботом S7 Airlines и не имеет доступа к персональным данным, бронированиям или билетам пассажиров.

## Что есть в проекте

```text
s7-chatbot/
│
├── chatbot.py
├── test_chatbot.py
├── requirements.txt
├── README.md
└── .gitignore
```

## Описание файлов

| Файл | Описание |
|---|---|
| `chatbot.py` | Основной файл чат-бота |
| `test_chatbot.py` | Автоматические тесты для проверки функций бота |
| `requirements.txt` | Список библиотек, которые нужно установить |
| `README.md` | Описание проекта и инструкция по запуску |
| `.gitignore` | Список файлов и папок, которые не нужно загружать на GitHub |

## Используемые библиотеки

В проекте используются:

- `pymorphy3` — для лемматизации русских слов;
- `nltk` — для разбиения текста на слова;
- `python-telegram-bot` — для запуска Telegram-бота;
- `unittest` — для автоматических тестов, устанавливать отдельно не нужно.

## Установка

Сначала установите зависимости:

```powershell
pip install -r requirements.txt
```

Или так:

```powershell
py -m pip install -r requirements.txt
```

## Запуск бота

Запуск основного файла:

```powershell
python chatbot.py
```

Или:

```powershell
py chatbot.py
```

В файле `chatbot.py` можно выбрать режим запуска:

```python
mode = "telegram"
# mode = "console"
```

Для запуска консольной версии нужно поставить:

```python
mode = "console"
```

Для запуска Telegram-версии нужно поставить:

```python
mode = "telegram"
```

## Команда /start в Telegram

После команды `/start` бот отправляет приветствие:

```text
Здравствуйте! Я S7-бот, помощник для пассажиров авиакомпании S7 Airlines. Напишите вопрос о поездке, «помощь» или «выход», чтобы завершить диалог.
```
